# Algoritmos e Programação Orientada a Objetos (POO)

Este repositório foi criado com o objetivo de organizar, centralizar e documentar meus estudos e práticas de programação utilizando Python.

O conteúdo está dividido em dois grandes pilares: Algoritmos e Programação Orientada a Objetos (POO). Ao longo do repositório, são apresentados exercícios, desafios e implementações desenvolvidos com o intuito de aprimorar a lógica de programação, a capacidade de resolução de problemas e a aplicação dos principais conceitos da linguagem Python.

## Linguagem utilizada

Todo o conteúdo deste repositório é desenvolvido utilizando Python, uma linguagem de programação de alto nível, conhecida por sua sintaxe simples e por sua ampla utilização em diferentes áreas da computação.

### Os códigos são escritos buscando priorizar:
    Clareza e organização
    Boas práticas de programação
    Eficiência dos algoritmos
    Facilidade de compreensão
    Aplicação dos conceitos estudados

## Algoritmos

A seção de Algoritmos reúne exercícios e problemas voltados principalmente para o desenvolvimento da lógica de programação e resolução de problemas computacionais.

### Entre os conteúdos trabalhados estão:

    Estruturas condicionais (if, elif, else)
    Estruturas de repetição (for e while)
    Entrada e saída de dados
    Vetores e listas
    Strings
    Operações matemáticas
    Funções
    Recursividade
    Ordenação e busca
    Manipulação de dados
    Complexidade de algoritmos

## Programação Orientada a Objetos

A seção de Programação Orientada a Objetos apresenta implementações utilizando os principais conceitos do paradigma orientado a objetos em Python.

### Entre os conceitos estudados estão:

    Classes e objetos
    Atributos e métodos
    Construtores
    Encapsulamento
    Herança
    Polimorfismo
    Abstração
    Classes abstratas
    Reutilização de código

## Objetivo

O principal objetivo deste repositório é servir como um registro da evolução dos estudos em programação, reunindo exercícios e projetos desenvolvidos durante o aprendizado.

Além de servir como material de consulta, o repositório também busca fortalecer conhecimentos fundamentais para o desenvolvimento de software, como raciocínio lógico, resolução de problemas, estruturas de dados, organização de código e modelagem de sistemas.
